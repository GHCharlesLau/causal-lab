01 the language

Nodes and arrows

A picture
of the assumptions.

Each node is a variable. Each arrow is a direct causal claim. The graph is not the world; it is the argument you are willing to defend.

Causal inference starts with a conditional independence assumption: the potential outcomes are independent of treatment, given the right variables. A graph is a compact way to say which variables those are — and which ones will make things worse.

Dependence flows along paths. Three small structures are enough to read almost any argument:

Chain

A → B → C

A and C are dependent. Condition on B and the path is blocked.

Fork

A ← B → C

A and C are dependent through their common cause. Condition on B and the backdoor closes.

Collider

A → B ← C

A and C are independent. Condition on B and the path opens — explaining away.

the target (Y0, Y1) ⊥ T | X

The backdoor criterion

To identify the effect of T on Y, condition on a set X that blocks every path between T and Y that enters T through an arrow. Do not condition on colliders or mediators.

read it aloud

“Education and wage share a cause: intelligence.” If you cannot say the graph in one sentence, you do not have a graph yet.

the hard part

The arrows are assumptions. The data can test implications, but they cannot prove the direction of an arrow.

02 the workbench

Three structures, one graph

Click a node.
Watch the path.

Each scenario is a different way a comparison goes wrong. Click the conditionable node and see whether the path opens or closes.

Conditioning is not a neutral act. On a fork it closes a backdoor; on a collider it opens one; on a mediator it closes the effect you are trying to measure. The graph tells you which is which before you touch the data.

try the three

Condition on Intelligence, then reset. Switch to Collider and condition on Investments. Then try the Mediator. The verdict changes every time.

the rule of thumb

If a variable is a common cause, control it. If it is a common effect, do not. If it is a channel, controlling it changes the question.

03 confounding

The common cause

Close every
backdoor.

Confounding happens when treatment and outcome share a cause. The fix is to block every backdoor path — not to add every variable you can measure.

Education and wage share intelligence as a cause. More intelligent people tend to get more education and earn more, regardless of what schooling does. If we compare people with the same intelligence, the remaining difference in wages is more plausibly the effect of education.

Sometimes the common cause is unmeasured. The book’s example uses intelligence, which is hard to measure directly, but has measurable proxies: SAT scores and family income. If intelligence affects education only through SAT, then conditioning on SAT blocks that path, even without measuring intelligence itself.

the backdoor criterion X blocks every path from T to Y that enters T through an arrow  ⇒  (Y0, Y1) ⊥ T | X

The proxy is not the cause

Controlling for SAT can close a path, but it does not turn SAT into intelligence. If the proxy is a noisy measure, some bias remains. A graph tells you which path you closed; it does not promise the measurement is perfect.

the question

Which paths enter treatment through an arrow? Those are the backdoors. The causal path leaves treatment through an arrow; do not block it.

the limit

If an unmeasured confounder points directly at treatment and outcome, no measured proxy eliminates the bias. It can only reduce it.

04 selection bias

When controlling hurts

Do not condition
on the effect.

A collider is a common effect. Conditioning on it opens a path that was closed. A mediator is a channel. Conditioning on it closes the effect you want.

Imagine education is randomised, so the naive comparison is clean. Then someone insists on controlling for investments. Investments is caused by education and by wage: it is a collider. Among people who invest, the uneducated must be especially high-earning to invest; the educated can invest for other reasons. Conditioning on investments makes education and wage dependent for a reason that has nothing to do with the effect.

The same logic applies to a mediator. Education raises wages partly by making white-collar jobs more likely. If we control for white-collar status, we close that channel and estimate only the part of the effect that does not run through it. The total effect looks weaker — or disappears.

The paradox

Selection bias can be fixed by doing nothing. When a variable is a common effect or a channel, adding it to the regression is not caution; it is a new assumption with a new bias.

The kitchen-sink regression

“Control for everything” is not a design. It can open colliders, block mediators, and make a randomized experiment look broken. Start with the graph.

one test

Ask of every control: is it a cause of treatment, an effect of treatment, or both? The answer decides whether it belongs on the right-hand side.

the honest sentence

“We condition on intelligence to close the backdoor; we deliberately do not condition on investments or white-collar work.”

05 key ideas

Carry these forward

Four things
to keep.

  1. A graph is a set of assumptions. Drawing it makes the identification argument inspectable before the estimate exists.
  2. Block every backdoor. Condition on common causes; do not condition on the causal path.
  3. Colliders are traps. Conditioning on a common effect opens a path that was closed. Selection bias is often self-inflicted.
  4. Mediators change the question. Controlling a channel estimates a partial effect, not the total effect.

The most common mistake

Adding a variable because it is available. Availability is not a causal argument. The graph decides.

to remember

Draw the graph before you write the regression. Then write the regression that matches the graph.

06 practice

Check yourself

Can you
defend it?

Four short questions. Answer first, then open the field note.

01 What is the difference between a fork and a collider?

A fork has a common cause: A ← C → B. A and B are dependent, and conditioning on C blocks the path. A collider has a common effect: A → C ← B. A and B are independent, and conditioning on C opens the path.

02 Why can conditioning on a collider create bias?

Conditioning on a common effect restricts the sample to one value of the effect. Within that group, the causes become negatively associated: if one cause is absent, the other must be present to produce the effect. That association is not causal.

03 What does the backdoor criterion require?

A set X that blocks every path between treatment and outcome that enters treatment through an arrow, while leaving the causal path out of treatment open. If X does that, the potential outcomes are conditionally independent of treatment given X.

04 Why can controlling for a mediator make an effect look weaker?

A mediator is part of the causal channel. Conditioning on it compares units at the same mediator value, which removes the part of the effect that operates through the mediator. The remaining estimate is a partial effect, not the total effect.
