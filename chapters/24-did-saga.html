01 birth

The promise of panel data

Each city,
its own control.

A staggered rollout: three cohorts, a before-and-after comparison, and a set of never-treated cities.

A city’s baseline installs are captured by a unit effect; the common trend and seasonality by a time effect. The two-way fixed-effects model writes installs as a treatment indicator plus both effects.

With a constant treatment effect of 1, the TWFE estimate is exactly 1.000. It recovers the effect because the model’s implicit counterfactual — the control trend projected to the treated level — is correct.

Why it works

Unit effects absorb fixed differences; time effects absorb the common trend. The treatment coefficient is the remaining before-and-after difference.

the decomposition

TWFE is a weighted average of all possible 2×2 DiDs: early vs never, late vs never, early vs late, and late vs early.

the hidden assumption

The weights must be positive and the effects must be constant over time. If not, the average can go wrong.

02 death

Time heterogeneity

The effect
matures. TWFE doesn’t.

Make the treatment effect ramp up over ten days. TWFE now averages comparisons that use already-treated units as controls.

The true ATT is 0.8544. TWFE returns 0.7868. The model is not failing because parallel trends are violated; it is failing because its functional form forces one constant effect, and its implicit weights use the early-treated cohort as a control for the late-treated cohort.

The early cohort is still climbing when the late cohort is treated. Its rising outcome looks like a steeper control trend, so the late cohort’s counterfactual is projected too high — and its effect is underestimated.

Goodman-Bacon

TWFE can be decomposed into 2×2 DiDs. The “late vs early” comparison uses an already-treated group as the control, which contaminates the estimate.

the formula

Under heterogeneous timing, the probability limit is VWATT − ΔATT. The extra term is the change in the ATT over time; it biases the estimate.

03 the reversal

Two cohorts, wrong sign

Negative effect,
positive estimate.

A minimal example with no trend: the treatment reduces installs by 0.1 per day. TWFE says +0.05.

The early cohort’s effect is negative and decreasing. When the late cohort is treated, the early cohort is used as a control. Its falling outcome makes the late cohort’s counterfactual slope downward and shifts its level down, until the counterfactual sits below the treated outcome.

The true ATT is −1.219; the TWFE estimate is +0.050. This is not a small bias. It is a sign reversal.

The plot is not the problem

The cohort paths clearly show a negative effect. The estimator fails because of the counterfactual it constructs from the early-treated control, not because the data are uninformative.

The lesson

“Negative weights” is not an abstraction. An already-treated unit can enter a comparison as a control and pull the estimate in the opposite direction.

the fix

Do not use already-treated units as controls. Estimate cohort-specific effects or use a estimator designed for staggered adoption.

the caution

A positive TWFE coefficient is not evidence of a positive effect when treatment timing is staggered and effects change over time.

04 event study

A tempting non-fix

More dummies
are not enough.

Adding a dummy for every period relative to treatment makes the model flexible. It still uses already-treated units as controls.

The event-study model replaces one treatment indicator with a set of relative-time dummies. That captures time heterogeneity in the effect, but it does not change the set of comparisons. The early-treated cohort is still a control for the late-treated one.

The result is a set of event-study coefficients with strange spikes and a positive pre-treatment effect, even though there is no anticipation. Flexibility without fixing the comparison is not enough.

The diagnosis

Event studies can be useful for diagnostics. They are not automatically a solution to staggered-adoption bias.

What changes

The fix must change which units serve as controls, or estimate effects cohort by cohort so that already-treated units are not used as clean controls.

the tell

A pre-treatment “effect” that is not zero is a warning. It can come from anticipation, but also from contaminated comparisons.

the next try

Interact treatment with cohort and date. That allows the effect to vary by both, which is the flexible functional form the next section uses.

05 enlightenment

A flexible functional form

Let the effect
vary by cohort and date.

Interact treatment with cohort and date dummies. The model can now represent a different effect for every cohort-day.

Instead of one τ, estimate τgt for each cohort g and date t. This is a large model — 467 parameters — but it recovers the true ATT of 0.854411 exactly.

Dropping pre-treatment dates and the never-treated cohort reduces the model to 271 parameters and still recovers 0.854411. The counterfactual now sits where it should: near the control cohort, not on a spurious trend.

The catch

This fixes the functional form, not the independence assumption. Parallel trends is still required, and it is more restrictive than it looks.

the implementation

Create cohort dummies and cohort-specific date columns; interact each with treatment. Drop pre-treatment dates under no anticipation.

the warning

More parameters mean more variance. The point is to model the effect’s time path, not to fit every cell.

06 key ideas

Carry these forward

Four things
to keep.

  1. TWFE is a weighted average of 2×2 DiDs. When already-treated units serve as controls, the weights can be negative and the average can be wrong.
  2. Time heterogeneity breaks the constant-effect model. An effect that matures can be underestimated; an effect that fades can be reversed.
  3. Event studies are not a cure. They add relative-time dummies but do not fix which units are used as controls.
  4. Cohort×date interactions restore flexibility. Estimate a separate effect by cohort and date, and drop clean pre-periods to reduce the parameter count.

The sentence to avoid

“TWFE is biased, so DiD is dead.” The functional-form problem has a fix; the parallel-trends assumption remains the harder question.

to remember

Plot the cohort paths, decompose the comparisons, and ask which units are serving as controls.

07 practice

Check yourself

Can you
defend it?

Four short questions. Answer first, then open the field note.

01 Why does TWFE recover 1.000 in the constant-effect case?

With a constant effect and parallel trends, every 2×2 DiD is unbiased and the weights are positive. The weighted average equals the true effect.

02 Why is the maturing effect underestimated?

The early-treated cohort is still climbing when the late cohort is treated. Using it as a control makes the late cohort’s counterfactual trend too steep, shrinking the estimated effect.

03 Why can TWFE get the sign wrong?

Already-treated units can receive negative weights in the decomposition. A fading negative effect in the early cohort can push the late cohort’s counterfactual below its treated outcome.

04 Does the cohort×date model solve every DiD problem?

No. It fixes the functional-form problem by allowing effects to vary by cohort and date, but parallel trends and no unobserved confounding are still required.
