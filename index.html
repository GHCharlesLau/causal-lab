Each chapter follows the same shape: a story, a lab, a formula you can read, and a short defense. Every page is open, and every number is traced to its source.

How to read it

Read. Play. Defend.

01

Read the story

Start with the decision, not the estimator. Every method exists because a naive comparison failed in a specific way.

02

Break the lab

Move the slider, change the match, reveal the counterfactual. The point is to build an intuition you can feel when the numbers move.

03

Write the defense

End with the assumption in plain language: what must be true for this comparison to be credible, and what would break it?
